# JH-D400X joystick housing

A 3D-printed housing for the **JH-D400X** 4-axis potentiometer joystick module ([AliExpress](https://www.aliexpress.com/item/1005001844154962.html)). The module's potentiometers connect to the brain board's pot header (H4) and are read by the ADS1115.

![JH-D400X housing](jh-d400x_enclosure.png)

| File | Use |
|---|---|
| `jh-d400x_enclosure.3mf` | Ready to slice and print |
| `jh-d400x_enclosure.f3d` | Fusion 360 source |
